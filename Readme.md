# 🚀 Ranjan's Landing Page'

A modern, interactive, comic-inspired Landing page website showcasing AI development, automation systems, and technical expertise. Built with advanced animations, Three.js 3D graphics, GSAP interactions, and a unique Spider-Verse-inspired design.

## 🌟 Features

* 🎨 Comic-book inspired UI/UX design
* 🌐 Interactive Three.js 3D cityscape
* 🕸️ Dynamic web-shooting scroll animation
* ✨ Smooth GSAP animations and transitions
* 🖱️ Custom animated cursor effects
* 📱 Fully responsive layout
* 🎯 Interactive service cards with 3D tilt effects
* 📊 Animated statistics counters
* 🔗 Social media integration
* ⚡ Fast and lightweight static website
